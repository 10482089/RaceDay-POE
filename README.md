# RaceDay - Event Management System

## System Description
RaceDay is a web-based event management system for South African road running, walking, and cycling events. It helps Organisers manage events and Participants enter races.

## User Roles
1. **Organiser**: 
   - Create, edit, and delete events
   - Manage event categories
   - View participant enrolments
   - Capture results (finish times and positions)

2. **Participant**: 
   - Browse upcoming events
   - Enrol in events
   - View personal enrolment history
   - Track race results
